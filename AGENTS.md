# Repository agent guidance

- Use `$backend-typescript-quality` for NestJS/backend TypeScript implementation and backend code review.
- Use `$frontend-typescript-quality` for React/frontend TypeScript implementation and frontend code review.
- For cross-stack changes, apply each skill only to its relevant part. Do not load both for unrelated work.
- `PLAN.md` is the accepted architecture baseline; consult it for architecture and data-model decisions rather than duplicating those rules here.
